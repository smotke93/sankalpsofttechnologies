# SankalpSoftTechnologies website

A responsive one-page business website built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — page content and sections
- `css/styles.css` — layout, colors, responsive styling
- `js/main.js` — mobile navigation, footer year, and contact form mailto behavior
- `assets/favicon.svg` — browser tab icon

## Preview locally

1. Download and unzip this folder.
2. Open `index.html` in a browser.

For a more reliable local preview, open the folder in Visual Studio Code and use the Live Server extension.

## Contact form note

The form does **not** send data to a server. On submit, it opens the visitor's default email app with a prefilled email to `sankalpsofttechnologies@gmail.com`. The visitor must press Send. For a form that submits directly from the website, connect a form service or your own backend before launch.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `sankalpsoft-website`.
2. Upload all files and folders while keeping the structure intact.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Once GitHub Pages publishes the site, add your custom domain in the Pages settings and configure the DNS records at GoDaddy as GitHub instructs for your domain.

## Before launch

- Confirm your business details and service descriptions.
- Test all links and the contact form on desktop and mobile.
- Connect your custom domain and verify HTTPS.
- Add a privacy notice if you later collect visitor information or use analytics.
